# Example cases

These examples demonstrate two entry routes, not two predetermined answers.

| Case | Entry route | Main lesson | Evidence ceiling |
|---|---|---|---|
| [AI short drama](ai-short-drama/README.md) | Existing industry | A production-cost shock can widen one node while tightening distribution, validation, and feedback. | Sourced historical reconstruction with ordinal inference. |
| [JEV-like bounded decisions](jev-technology-shock/README.md) | New technology | A capability class may change the software division of labor before industry adoption or vendor rent is visible. | Scoping forecast with explicit adoption bridges. |

Do not grade a new run by whether it repeats these conclusions. Grade whether it freezes a coherent case, traces effective alternatives, separates system dependence from owner capture, and leaves observable falsifiers.
