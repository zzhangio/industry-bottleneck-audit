## Remaining Visual Limitations

- The static card targets 900-1100 px Markdown rendering. It preserves its wide composition on phones rather than shrinking into a different topology; phone-sized image text is necessarily smaller. The interactive sibling reflows instead.
- No PNG export is included because the brief permits exactly three new files. GitHub will not render the HTML itself as a README image.
- Mobile node details are inline below the diagram, avoiding an overlay but requiring scrolling. Keyboard focus remains at the selected node.
- Geometry is an editorial qualitative illustration, not a calibrated bottleneck or flow model. There is no quantitative before/after overlay.
- The static card intentionally omits the evidence ledger and long boundary prose; its accessible description preserves scope and caveats, while the linked interactive view carries the audit. A PNG loses that description, so promotion must supply meaningful Markdown alt text and the adjacent case/cutoff context.
- The system font stack may render differently on other operating systems. Independent primary-agent factual review and promotion remain outstanding.
