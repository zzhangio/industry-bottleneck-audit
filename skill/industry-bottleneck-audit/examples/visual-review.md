# Example Visual: Scope And Limitations

The [example HTML](minimal-audit-visual.html) is generated from [the example bundle](minimal-audit-bundle.json) by [the renderer](../scripts/render_audit_visual.py). It demonstrates the interface, not a validated industry forecast.

- Small topologies are the intended use; dense feedback loops or many crossing edges need a reduced editorial view.
- Wide graphs and tables may use local horizontal scrolling.
- Timeline ordering extracts dates from free-text horizons and is not a strict temporal model.
- Full assistive-technology certification is not claimed.

For new or changed visuals, apply [the visual acceptance checks](../references/visualization.md#acceptance-check) and record actual checks and outstanding limitations with the delivered artifact. This note does not certify subsequent changes.
